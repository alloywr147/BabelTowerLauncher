# 已知限制

- 动态界面需要 Microsoft Edge WebView2 Runtime；缺失时提示安装微软官方运行时。
- 等高线背景默认开启动效，上限 60 fps；窗口隐藏时停止绘制。实际性能取决于硬件及窗口大小。
- 外部修改目录、安装内容或接口配置后，应重新检查。启动器不替代 Steam 游戏文件验证。
- 游戏运行时仅可重启所选桥；修复或替换游戏文件需要退出游戏。
- 更新依赖 GitHub 连通性、API 配额、附件命名与校验信息；Mod 仍可手动导入压缩包。
- 修复与更新备份用于恢复，可能随使用积累。
- 基础连接和接口检查通过，仍需在游戏内确认 Mod 加载和翻译效果。
- 当前 WebView2 界面提供修复和报告预览；WinForms 备用界面保留基础操作。
