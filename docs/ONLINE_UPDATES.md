# 使用与在线更新

## 设置路径与启动

在设置中自动检测或选择 Deadlock 根目录及专用 BabelTower 目录。已有完整包可选择其文件夹；没有时在 Mod 更新页下载官方 Windows 完整包。点击启动，待本地桥、翻译接口及安装文件检查通过后确认进入游戏。

## Mod 网页设置

1.2.1 起，用顶部“Mod 设置”或游戏内 /tr 打开本地网页设置页。启动器会先检查所选主桥，缺失时启动，再打开 http://127.0.0.1:<配置端口>/ui。旧版游戏内面板可用 /tr panel 打开。

## 低延迟通道

包含 core/bridge_https.js 的包会同时处理主桥与低延迟进程。主桥已运行时仍检查并补启动缺失的快通道。8792 被其他版本占用时保留原进程，不尝试强行替换。

首次按 Mod 的 scripts/gen_bridge_cert.ps1 -Trust 说明配置本机证书，之后完全退出 Steam（包含托盘）并重新打开。启动器不会自动生成或信任证书，不会替你退出游戏或 Steam。

通道状态分别识别旧版不支持、缺少证书、证书无效/未信任、端口被占用、进程未就绪、HTTPS 检查失败和本地可用。证书文件存在、进程存在或主桥正常均不能单独证明快通道可用。游戏端最终效果需实际检查。

## 在线更新

更新页顶部切换“Mod 更新 / 启动器更新”，下面只有“检查更新”；发现新版后变为“下载并安装”，进行中可用同一按钮取消。Mod 只读取 c1375rick/BabelTower 的发布附件；启动器只读取 alloywr147/BabelTowerLauncher。下载完成后校验体积及 SHA256。

安装 Mod 整包替换旧版本，不迁移旧词典和配置。在新包启动前设置 ui.outgoing=translation，之后用户手动修改会保留到下一次整包更新。游戏运行中只下载，退出后再安装；失败保留旧包并恢复游戏文件。

启动器更新退出后自动替换并重新打开，保留 data。1.7 的发布标签为 v1.7，程序附件名为 BabelTowerLauncher-1.7-win64.zip。手动压缩包导入和简易模式均已移除。
