# 1.4：维护性与验证说明

本版本在 1.3.1 的基础上增加在线更新、自动更新提醒和主题切换。

## 对照 2026-10-05 的维护性审查报告

| 建议 | 本轮落实 | 后续独立重构 |
|---|---|---|
| 更新与界面分离 | PackageInstaller 组织 Mod 安装；OfficialUpdates 查询、下载与校验；DownloadCache 管理已下载包；SelfUpdater 组织软件暂存与后台交接 | 旧 UI 其他业务流程继续拆分 |
| 明确事务结果 | VPK 恢复逐项执行，UpdateTransactionException 携带恢复状态；配置回滚检测外部修改；SelfUpdateFailure 区分完整恢复和不完整恢复；提交后清理警告独立呈现 | Core.Commit 的 production 分支与回调接口仍保留 |
| 异步恢复 | 更新服务在 Task.Run 中执行；后台交接使用 await；下载可取消，ready 后取消也不退出安装 | 统一其他事件入口及错误类型 |
| 状态过期保护 | 保留 Connectivity.Revision、上下文变化与桥重启使在线结果失效的机制 | 页面和操作状态枚举、视图封装尚未纳入 |
| 可复现构建与测试 | scripts/build.ps1、scripts/test.ps1 统一编译依赖；.NET Framework 4.8、Windows x64；临时目录和静默程序验证 | 标准项目文件及消除全局可变存储路径 |
| 格式、命名与公共规则 | 新增服务职责分离，复杂边界有设计注释 | 全项目格式、命名、配置规则和只读查询副作用整理尚未纳入 |

## 验证

加入明暗主题与启动更新弹窗后的完整测试：215 项检查通过。新增检查覆盖主题记忆、文字对比度、未保存输入与下载状态保留、拖放恢复当前主题颜色，以及主题偏好不覆盖游戏配置。启动检查覆盖两个仓库独立查询、单一来源失败、取消、版本比较、每次运行仅提示一次，以及弹窗更新选项与稍后按钮。测试使用临时目录、模拟桥、临时本地 HTTP 服务与静默测试程序，没有启动真实 Deadlock、真实桥或执行实际 Mod 安装。

自更新端到端测试验证：父进程保持运行时不替换；后台就绪后父进程退出；替换完成自动重新打开；保留 data；取消交接后，即使父进程后来退出也不安装。文件占用、备份准备失败及回滚另有检查。

实际联网验证读取两个公开仓库，官方 Mod 1.0.8 完整包与启动器 1.3.1 附件均通过体积、SHA256、解压和版本/文件结构检查。没有把下载包安装到用户目录。

只读复审已解决退出竞态、准备失败不重开、临时清理遮蔽恢复异常、交接取消失效等重要问题。一个低优先级余项：短名称的后台更新副本及恢复资料暂保留，重复更新会积累，可在后续加入已完成任务清理。

1.4 发布构建新增验证：识别 v1.5 两段版本标签并归一到 1.5.0，按数值排序 1.9 / 1.10，严格匹配发布标签与压缩包名称；后台替换测试使用 v1.5 安装包。
