# 已知问题与验证边界

本列表来自源码审查和隔离复现，记录当前 1.3.1 仍继承的后端限制。视觉更新没有修复这些问题。

| 情况 | 当前行为 | 使用建议 |
| --- | --- | --- |
| 导入相同版本的修复包 | 目标版本目录已存在，更新被拒绝 | 暂不提供同版本自动重装 |
| 旧安装包损坏 | 完整性校验可能阻止导入完整新版 | 保留旧目录，先收集错误记录 |
| 游戏加载配置不满足要求 | 可能在更新提交后才报告安装失败 | 更新前运行诊断，确认安装条件 |
| 不同启动器同时更新同一安装位置 | 缺少共同的文件事务锁，失败回滚可能覆盖另一事务 | 不同时使用多个版本执行更新 |
| 外部修改配置或 VPK | 部分旧检查状态不会立刻失效 | 主动重新检查，不依赖先前绿色状态 |
| 检测到的旧包不在既有安装根目录内 | 检测结果与根目录可能不匹配 | 保存前核对安装根目录与已有版本位置 |
| settings.json 字段显式为 null | 部分路径操作可能异常 | 反馈配置格式，分享前去掉个人路径 |
| 小屏幕或高 DPI | 固定布局尚未充分验证 | 当前推荐能容纳约 1016×799 窗口的工作区 |

目前自动化覆盖文件事务的普通异常、目录检测、拖放、安装诊断、连接状态以及隐藏窗口导航。没有模拟断电恢复，也没有在测试中启动真实 Steam、Deadlock 或 Mod 桥。

后续优先项：提交前安装验证、修复安装、共享操作锁、同版本重装、配置变动失效、小窗口布局。
