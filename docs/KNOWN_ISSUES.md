# 已知限制

- 需要 Windows x64、.NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。
- 完整等高线界面使用 GPU；1.7 不包含简易模式。
- 新版低延迟通道需要 Mod 提供的脚本与本机受信任证书。证书信任变更后 Steam 必须完全重启；启动器不会代为操作。
- “本地可用”验证本机通道，游戏是否已采用快通道需要实测。未配置时可使用原有慢通道。
- 在线更新依赖 GitHub 连通性、配额及正确的版本标签、附件名和 SHA256。
- 旧版 Mod 不包含网页设置或低延迟脚本时，会明确提示。
- 游戏运行时可恢复所选桥；游戏文件修复与 Mod 替换需要先退出游戏。
- 备份会随更新累积，应在验证成功且不再需要回滚时自行整理。
