# 1.6 实现与验证

简易模式为纯黑界面，不创建画布或加载三维场景；完整模式通过本地延迟加载保留等高线界面。两种模式共用业务服务与单按钮更新页面；手动压缩包导入区及其原生命令已移除。

InterfacePreferences 读取本地模式记录，缺失、无效或无法读取时使用简易模式；保存使用临时文件与原子替换。程序包不携带任何 data，因此不继承作者的模式选择。自更新继续保留每位用户已有 data。

WebView2 仅允许本地页面调用白名单命令。在线更新由原生代码选择固定仓库，不接受任意外部下载地址。

scripts/test.ps1 验证默认模式、选择持久化、目录发现、安装事务、在线更新、自更新、诊断、连接证据和修复；scripts/test-simple.ps1 验证实际 WebView2 页面、两种模式切换及无手动导入区。web 中 npm test 验证完整模式的动画调度与鼠标缓动。

测试使用隔离夹具、模拟服务和屏幕外窗口。真实游戏内 Mod 加载与翻译效果仍需实际使用验证。
