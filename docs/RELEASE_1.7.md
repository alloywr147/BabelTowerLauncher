# 巴别塔启动器 1.7

- 适配 Babel Tower 1.2.1，包含原作者 PR #1 的低延迟通道及网页设置支持。
- 主桥已经运行时，也会检查并补启动缺失的低延迟进程；停止或重启处理所选版本的两种进程。
- 新增“Mod 设置”入口，打开所选桥的本地网页设置页。
- 新增“配置证书”按钮：确认后调用所选 Mod 官方脚本，验证本机证书与信任状态；失败不会误报成功。
- 独立显示低延迟通道状态，校验证书、端口归属与实际 HTTPS 响应，提示缺少证书或未信任等原因。
- 移除简易模式，仅保留完整等高线界面，支持深浅色主题。
- 保留在线更新、一键修复、诊断报告、启动检查和新包默认“仅译文”。

下载 BabelTowerLauncher-1.7-win64.zip，完整解压后运行“巴别塔启动器.exe”。压缩包不含 Mod 本体和本机证书。

升级前退出旧启动器，替换程序、assets 和 tools，保留 data。已有简易模式记录会被忽略。首次使用快通道可点击“配置证书”，确认 Windows 安全警告后，完全退出并重启 Steam（包括托盘），再点击“重启桥”。

验证：本地功能和界面测试；游戏内低延迟翻译及网页配置推送待实际使用验证。建议完成游戏测试后再发布正式版。
