# 巴别塔启动器 1.6

- 首次打开默认纯黑简易模式，主菜单仅保留“启动、更新、设置”，白色粗体大字。
- 右上角“退出简易模式”切回完整界面，完整界面可切回来；记住每位用户自己的选择。
- 简易模式不加载三维背景，完整模式保留等高线界面。
- 两种界面都移除“拖入新版压缩包／选择压缩包”模块，Mod 通过 GitHub 在线更新。
- 更新页只保留一个操作按钮：“检查更新”，发现新版后变为“下载并安装”；顶部可切换 Mod 和启动器更新。
- 保留桥与翻译接口检查、一键修复、报告、启动更新提醒和更新失败恢复。

下载 BabelTowerLauncher-1.6-win64.zip，完整解压后运行“巴别塔启动器.exe”。需要 Windows x64、.NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。

从旧版本升级前退出启动器，覆盖程序、assets 和 tools，保留 data 即可沿用路径、配置和模式选择。新安装不含作者个人 data，默认简易模式。

压缩包不含 Mod 本体，首次使用可在更新页下载官方 Windows 完整包。
