# 1.7 晚间游戏测试

本地自动检查不替代游戏内验证。本测试无需删除原 1.6 或现有 Mod。

1. 启动桌面“巴别塔启动器 1.7”，确认完整界面、等高线背景及深浅色切换。
2. 在设置中自动检测游戏目录、巴别塔目录和已有完整包；需测试 Babel Tower 1.2.1 的新功能时，选择或安装该版本。
3. 点击“Mod 设置”，确认桥启动后能打开所选版本的本地网页设置页。
4. 若诊断页提示证书缺失或未信任，点击“配置证书”，在应用内确认后核对 Windows 安全警告中的 BabelTower-localhost 并选择“是”；应显示信任验证成功。取消 Windows 确认时应提示“仍未信任”。之后完全退出 Steam，包括托盘，再打开 Steam并点击“重启桥”。启动器不会自动退出 Steam。
5. 检查主桥、翻译接口和安装文件，再看低延迟通道是否显示“本地可用”。缺失/未信任等状态应明确提示，不应误显示正常。
6. 从启动器进入游戏。用 /tr 打开网页设置，实际试译，确认新版快速通道能够工作；网页修改并保存一个设置后，确认游戏内随后生效。
7. 正常退出并重新打开启动器，确认不会出现简易模式，已保存路径及主题仍在。

若不正常：先保留原 1.6 和 Mod，点“导出报告”，记录界面通道状态及游戏里的现象。主桥正常与 HTTPS 本地可用不能代替游戏端验证。
