# 已知限制与验证范围

- 同版本修复包不支持直接覆盖已有版本目录。
- 不同启动器同时更新相同安装目录没有共同的事务锁，请避免并行安装。
- 外部修改翻译配置或 VPK 后，需要主动重新检查连接和安装状态。
- 固定窗口布局尚未充分验证小屏幕和高 DPI，推荐至少能容纳约 1016×799 窗口的工作区。
- 在线更新依赖 GitHub 连通性、API 配额、规范附件名称以及 SHA256 校验值；不满足时仍可手动导入 Mod 压缩包。
- 自更新备份和短名称后台更新副本暂保留，多次更新会积累恢复资料。

自动化测试覆盖回滚、游戏文件保护、下载校验、更新交接、取消、配置保留、主题与更新弹窗。未模拟断电，未启动真实 Steam、Deadlock 或 Mod 桥；真实游戏连接效果需实际确认。
