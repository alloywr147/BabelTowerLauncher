# 巴别塔启动器 1.5

- 莱茵风格界面、MiSans 字体和实验室等高线动态背景，支持深浅色主题、缓慢起伏与鼠标局部波纹；动效默认开启。
- 一键修复 Mod 文件、addons 加载路径及桥日志配置，保留其他 Mod，变更前备份。
- 诊断报告先预览再保存，不包含配置原文、密钥、聊天日志或完整本地路径。
- 保留目录检测、拖放压缩包、GitHub 在线更新、启动更新提醒、桥检测和游戏启动流程。
- 启动隐藏旧界面，运行记录支持关闭，各页共用动态背景；更新与诊断布局更紧凑，设置页固定滚动条占位，减少切换闪屏。
- 图标采用 BT 等高线设计。

需要 Windows x64、.NET Framework 4.8 与 Microsoft Edge WebView2 Runtime。下载后完整解压，运行“巴别塔启动器.exe”；不包含 Mod 本体。

从 1.4 升级：退出启动器，覆盖程序、assets 和 tools，保留原 data 文件夹；也可使用在线更新。独立安装时可复制原 data/settings.json 与 data/appearance.json 沿用设置。

Release 标签为 v1.5，Windows 附件名称为 BabelTowerLauncher-1.5-win64.zip。源码 ZIP 用于开发，不是可运行程序包。
