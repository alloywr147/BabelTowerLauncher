# 1.6 使用说明

首次打开为纯黑简易模式，右上角可退出；完整界面可返回简易模式，选择独立保存在 data/interface-mode.txt。没有个人记录时默认简易模式，已有记录按用户选择恢复。

## 安装与启动

在设置中自动检测或选择 Deadlock 根目录和专用 BabelTower 安装目录。已有完整 Mod 时选择其文件夹；没有时打开更新页，检查官方版本并下载。

启动会先检查桥、本地服务、翻译接口、VPK 与加载配置，通过后由用户确认进游戏。诊断和修复从设置页进入。游戏运行时，文件修复和安装需退出游戏。

## 更新

Mod 更新只读取 c1375rick/BabelTower 官方 GitHub Windows 完整包，启动器更新只读取 alloywr147/BabelTowerLauncher 发布附件。下载前检查名称与来源，下载后校验体积和 SHA256。手动压缩包导入区已移除。

Mod 整包替换，旧配置和词典不迁移；游戏运行时仅下载，退出后再确认安装。检查与提交失败保留旧版本并尝试回滚。

启动器更新由后台程序等待退出，再备份、替换和重新打开，保留 data。替换失败保留恢复资料。

GitHub 发布标签为 v1.6，程序附件名为 BabelTowerLauncher-1.6-win64.zip。仅有源码或附件信息不符合规则时无法在线安装，请在 GitHub 确认发布信息后重试。

更新页顶部切换 Mod / 启动器更新，下面只显示“检查更新”；发现新版后同一按钮变成“下载并安装”。下载或检查进行中，可用同一按钮取消。检查失败可重试，不会擅自安装，也不会结束真实游戏。
